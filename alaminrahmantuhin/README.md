# Alamin Rahman Tuhin — Portfolio

Professional Flutter Developer portfolio website.

## Included
- Responsive single-page portfolio
- About, skills, projects, process and contact sections
- GitHub link
- Facebook/YouTube buttons ready to customize
- No framework required — plain HTML/CSS/JavaScript

## Publish with GitHub Pages
1. Create a GitHub repository, for example `alamin-portfolio`.
2. Upload `index.html`, `style.css`, and `README.md`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save. GitHub will provide the live website URL.

## Important
The exact Facebook and YouTube profile URLs were not available in the information I could reliably verify. Replace the placeholder links in `index.html` with your actual profile/channel URLs before publishing.
